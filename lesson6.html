💡 What is an Array?

Sometimes you need to store multiple pieces of data. Instead of creating 10 separate variables like score1, score2, score3... you can use an array!

An array is like a list or row of lockers. Each locker (called an element) has a number (called an index) that tells you where it is.

Important: Array indexes start at 0, not 1! So the first element is at index 0, the second at index 1, and so on.

📝 Example 1: Creating and Accessing Arrays
1 Storing and Printing Scores

This program creates an array of scores and prints each one!

📄 lesson6.cpp
#include <iostream> using namespace std; int main() { // Create an array of 5 scores int scores[5] = {85, 92, 78, 95, 88}; // Access and print each element cout << "Score 1: " << scores[0] << endl; // First element cout << "Score 2: " << scores[1] << endl; // Second element cout << "Score 3: " << scores[2] << endl; // Third element cout << "Score 4: " << scores[3] << endl; // Fourth element cout << "Score 5: " << scores[4] << endl; // Fifth element return 0; }
▶️ Output:
Score 1: 85
Score 2: 92
Score 3: 78
Score 4: 95
Score 5: 88
⚠️ Remember: Array indexes start at 0, so the first element is scores[0] and the last is scores[4]. There is no scores[5]!
📝 Example 2: Looping Through an Array
2 Using a For Loop with Arrays

For loops are perfect for going through every element in an array!

📄 lesson6.cpp
#include <iostream> using namespace std; int main() { // Create an array of 5 scores int scores[5] = {85, 92, 78, 95, 88}; // Use a for loop to print all scores cout << "All scores: "; for (int i = 0; i < 5; i++) { cout << scores[i] << " "; } cout << endl; // Calculate and print the average int sum = 0; for (int i = 0; i < 5; i++) { sum += scores[i]; } double average = sum / 5.0; cout << "Sum: " << sum << endl; cout << "Average: " << average << endl; return 0; }
▶️ Output:
All scores: 85 92 78 95 88
Sum: 438
Average: 87.6
💡 Tip: Use i < 5 in the loop condition. Since indexes go from 0 to 4, we stop when i reaches 5.
📝 Example 3: Finding Max, Min, and User Input
3 Score Analyzer with User Input

This program asks the user for 5 scores, then finds the highest, lowest, and average!

📄 lesson6.cpp
#include <iostream> using namespace std; int main() { int scores[5]; int sum = 0; // Ask user for 5 scores cout << "Enter 5 scores:" << endl; for (int i = 0; i < 5; i++) { cout << "Score " << i + 1 << ": "; cin >> scores[i]; sum += scores[i]; } // Find highest and lowest int highest = scores[0]; int lowest = scores[0]; for (int i = 1; i < 5; i++) { if (scores[i] > highest) { highest = scores[i]; } if (scores[i] < lowest) { lowest = scores[i]; } } // Print results cout << "\n📊 Results:" << endl; cout << "Highest score: " << highest << endl; cout << "Lowest score: " << lowest << endl; cout << "Average: " << sum / 5.0 << endl; return 0; }
💬 User Types:
85
92
78
95
88
▶️ Output:
Enter 5 scores:
Score 1: 85
Score 2: 92
Score 3: 78
Score 4: 95
Score 5: 88

📊 Results:
Highest score: 95
Lowest score: 78
Average: 87.6
💡 Tip: To find the highest, start with the first element as the highest, then compare with the rest. Same for lowest!
