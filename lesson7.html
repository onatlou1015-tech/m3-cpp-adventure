💡 What is a Function?

Think of a function as a recipe or a machine. You give it some ingredients (called parameters), it does something, and sometimes it gives you back a result (called a return value).

Functions help you:

  • ✅ Organize your code into smaller, manageable pieces
  • ✅ Reuse code without copying and pasting
  • ✅ Debug easier because each function does one thing
  • ✅ Share code with others more easily

You've already been using functions! main() is a function. cout and cin use functions too!

function parameters arguments return void call define
🏗️ Function Structure

📐 Parts of a Function

// Function structure: returnType functionName(parameterType parameterName) { // Code to execute return value; // (if returnType is not void) } // Example: int addNumbers(int a, int b) { int sum = a + b; return sum; }
  • returnType: What kind of data does it give back? (int, double, string, void, etc.)
  • functionName: What do you want to call it? (Use descriptive names!)
  • parameters: What information does it need to do its job?
  • return: What does it give back? (Only if not void)
📝 Example 1: Void Function (No Return)
1 Printing a Welcome Message

A void function does something but doesn't return a value.

📄 lesson7.cpp
#include <iostream> #include <string> using namespace std; // Function that prints a welcome message void printWelcome(string name) { cout << "Welcome, " << name << "!" << endl; cout << "Let's learn C++ together! 🚀" << endl; } int main() { // Call the function printWelcome("Alex"); printWelcome("Sarah"); return 0; }
▶️ Output:
Welcome, Alex!
Let's learn C++ together! 🚀
Welcome, Sarah!
Let's learn C++ together! 🚀
💡 Notice: We called the same function twice with different names! This is the power of functions — write once, use many times!
📝 Example 2: Return Function (With Return)
2 Calculator Functions

A function with a return value gives back a result that you can use.

📄 lesson7.cpp
#include <iostream> using namespace std; // Function to add two numbers int add(int a, int b) { return a + b; } // Function to multiply two numbers int multiply(int a, int b) { return a * b; } // Function to calculate the square of a number int square(int num) { return num * num; } int main() { int x = 5; int y = 3; // Call functions and store the results int sumResult = add(x, y); int multResult = multiply(x, y); int squareResult = square(x); cout << "Numbers: " << x << " and " << y << endl; cout << "Sum: " << sumResult << endl; cout << "Product: " << multResult << endl; cout << "Square of " << x << ": " << squareResult << endl; return 0; }
▶️ Output:
Numbers: 5 and 3
Sum: 8
Product: 15
Square of 5: 25
💡 Tip: You can also use the return value directly: cout << add(5, 3);
📝 Example 3: Functions with User Input
3 Grade Calculator Program

This program uses functions to calculate grades and determine letter grades.

📄 lesson7.cpp
#include <iostream> using namespace std; // Function to get the letter grade char getLetterGrade(int score) { if (score >= 90) return 'A'; else if (score >= 80) return 'B'; else if (score >= 70) return 'C'; else if (score >= 60) return 'D'; else return 'F'; } // Function to get a message based on grade string getMessage(char grade) { if (grade == 'A') return "🌟 Excellent work!"; else if (grade == 'B') return "👍 Good job!"; else if (grade == 'C') return "📚 Keep practicing!"; else if (grade == 'D') return "📖 You can do better!"; else return "😢 Don't give up! Study harder!"; } int main() { int score; cout << "Enter your test score (0-100): "; cin >> score; // Call functions char grade = getLetterGrade(score); string message = getMessage(grade); cout << "\n📊 Grade Report:" << endl; cout << "Score: " << score << endl; cout << "Grade: " << grade << endl; cout << "Message: " << message << endl; return 0; }
💬 User Types:
85
▶️ Output:
Enter your test score (0-100): 85

📊 Grade Report:
Score: 85
Grade: B
Message: 👍 Good job!
💡 Notice: Each function does one specific job — getLetterGrade calculates the grade, getMessage gives feedback. This makes the code easy to read and change!
⚖️ With vs Without Functions

📊 Why Functions Make Life Easier

❌ Without Functions ✅ With Functions
Copy-paste code everywhere Write code once, use many times
Hard to fix bugs (change in many places) Fix in one place, all calls updated
Long, messy code Clean, organized, easy to read
Hard to test and debug Each function can be tested separately
📋 Quick Reference

🔑 Key Code You Just Learned

void functionName(parameters) Creates a function that doesn't return anything
int functionName(parameters) Creates a function that returns an integer
return value; Returns a value from a function
functionName(arguments); Calls (uses) a function
int result = functionName(args); Stores the return value in a variable
void Means "returns nothing"
parameters Variables that receive data from the caller
arguments Actual values passed to a function
