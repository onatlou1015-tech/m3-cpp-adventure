💡 Making Programs Interactive

In Lesson 1, you learned how to print things to the screen. But programs are much more fun when they can talk back to you!

Today, you'll learn how to use cin (pronounced "see-in") to get input from the user. This makes your programs interactive — they can ask questions and respond based on what the user types.

cin >> user input interactive calculator
📝 Example 1: Getting User Input
1 Asking for a Name

This program asks the user for their name and then greets them personally!

📄 lesson2.cpp
#include <iostream> #include <string> using namespace std; int main() { // Create a variable to store the user's name string name; // Ask the user for their name cout << "What's your name? "; // Get the user's input and store it in 'name' cin >> name; // Greet the user personally! cout << "Hello, " << name << "! Nice to meet you!" << endl; return 0; }
💬 User Types:
Alex
▶️ Output:
What's your name? Alex
Hello, Alex! Nice to meet you!
💡 Tip: cin >> name; waits for the user to type something and press Enter. The typed text is then stored in the name variable!
📝 Example 2: Getting Numbers
2 Asking for Numbers

This program asks the user for their age and favorite number, then does some math!

📄 lesson2.cpp
#include <iostream> using namespace std; int main() { int age; int favoriteNumber; cout << "How old are you? "; cin >> age; cout << "What's your favorite number? "; cin >> favoriteNumber; int magicNumber = age + favoriteNumber; cout << "Your age is " << age << endl; cout << "Your favorite number is " << favoriteNumber << endl; cout << "Your magic number is " << magicNumber << "! ✨" << endl; return 0; }
💬 User Types:
15
7
▶️ Output:
How old are you? 15
What's your favorite number? 7
Your age is 15
Your favorite number is 7
Your magic number is 22! ✨
💡 Tip: You can chain cin statements together to get multiple inputs from the user!
📝 Example 3: Interactive Calculator
3 Calculator with User Input

This program asks the user for two numbers and does calculations on them!

📄 lesson2.cpp
#include <iostream> using namespace std; int main() { double num1, num2; cout << "===== SIMPLE CALCULATOR ===== " << endl; cout << "Enter first number: "; cin >> num1; cout << "Enter second number: "; cin >> num2; cout << "================================" << endl; cout << "Sum: " << num1 + num2 << endl; cout << "Difference: " << num1 - num2 << endl; cout << "Product: " << num1 * num2 << endl; cout << "Quotient: " << num1 / num2 << endl; return 0; }
💬 User Types:
10
3
▶️ Output:
===== SIMPLE CALCULATOR =====
Enter first number: 10
Enter second number: 3
================================
Sum: 13
Difference: 7
Product: 30
Quotient: 3.33333
⚠️ Important: Using double instead of int allows decimals in the calculations!
📋 Quick Reference

🔑 New Code You Just Learned

cin >> variable; Gets input from the user and stores it
cout << "Question? "; Asks the user a question
cin >> num1 >> num2; Gets two inputs in one line (advanced!)
double Use this for numbers with decimals
num1 + num2 You can do math right inside cout!

  • Print a summary of all their answers

What's your name? Sarah

Name: Sarah
Age: 14

🚀 Activity 2: BMI Calculator ⭐⭐ CHALLENGE

Your Task: Create a BMI (Body Mass Index) calculator!

  • Ask the user for their weight (in kilograms)
  • Ask the user for their height (in meters)
  • Calculate BMI using the formula: bmi = weight / (height * height)
  • Print the BMI result

Make it look like this:

===== BMI CALCULATOR =====
Enter your weight (kg): 70
Enter your height (m): 1.75

Your BMI is: 22.86
============================
💡 Hint: Use double for weight and height to get decimal results. The formula is bmi = weight / (height * height);
🌟 Bonus Challenge: Tip Calculator ⭐⭐⭐ ADVANCED

Your Task: Create a restaurant tip calculator!

  • Ask the user for the total bill amount
  • Ask for the tip percentage (e.g., 15 for 15%)
  • Calculate the tip amount
  • Calculate the total to pay (bill + tip)
  • Print a nice receipt

Make it look like this:

===== TIP CALCULATOR =====
Enter bill amount: $45.50
Enter tip percentage: 18

Bill: $45.50
Tip (18%): $8.19
Total: $53.69
============================
💡 Hint: Tip amount = bill * (tipPercent / 100). Use double for all numbers. Don't forget #include <iomanip> if you want to format decimals nicely!
