💡 Making Decisions in Code

Life is full of decisions! If it's raining, bring an umbrella. Otherwise, wear sunglasses.

In programming, we use if, else if, and else to make decisions. This is called conditional logic.

The computer checks a condition (like "is it raining?") and then decides what to do next.

if else else if > < == != >= <= && || !
🔍 Comparison Operators

Before we can make decisions, we need to compare things. Here are the comparison operators in C++:

📊 Comparison Operators

== Equal to 5 == 5 → true
!= Not equal to 5 != 3 → true
> Greater than 10 > 5 → true
< Less than 3 < 7 → true
>= Greater than or equal to 10 >= 10 → true
<= Less than or equal to 5 <= 8 → true

🔗 Logical Operators

&& AND — both conditions must be true (age > 18 && hasLicense) → true if BOTH
|| OR — at least one condition must be true (isWeekend || isHoliday) → true if EITHER
! NOT — reverses the condition !isRaining → true if NOT raining

📝 Example 1: Simple If Statement
1 Checking Your Age

This program checks if you're old enough to vote!

📄 lesson3.cpp
#include <iostream> using namespace std; int main() { int age; cout << "How old are you? "; cin >> age; // Check if age is 18 or older if (age >= 18) { cout << "🎉 You are old enough to vote!" << endl; cout << "🗳️ Go make your voice heard!" << endl; } return 0; }
💬 User Types:
18
▶️ Output:
How old are you? 18
🎉 You are old enough to vote!
🗳️ Go make your voice heard!
💡 Note: If the condition is false (age < 18), the program just skips the if block and does nothing.
📝 Example 2: If-Else Statement
2 Two Choices — If or Else

This program tells you if a number is even or odd.

📄 lesson3.cpp
#include <iostream> using namespace std; int main() { int number; cout << "Enter a number: "; cin >> number; // Check if the number is even if (number % 2 == 0) { cout << number << " is even! ✅" << endl; } else { cout << number << " is odd! ❌" << endl; } return 0; }
💬 User Types:
7
▶️ Output:
Enter a number: 7
7 is odd! ❌
💡 Tip: % is the modulo operator — it gives you the remainder after division. If a number % 2 == 0, it's even!
📝 Example 3: Else-If Chain
3 Multiple Choices

This program gives a grade based on your score.

📄 lesson3.cpp
#include <iostream> using namespace std; int main() { int score; cout << "Enter your test score (0-100): "; cin >> score; if (score >= 90) { cout << "Grade: A 🌟" << endl; cout << "Excellent work!" << endl; } else if (score >= 80) { cout << "Grade: B 👍" << endl; cout << "Good job!" << endl; } else if (score >= 70) { cout << "Grade: C 📚" << endl; cout << "Keep practicing!" << endl; } else if (score >= 60) { cout << "Grade: D 📖" << endl; cout << "You can do better!" << endl; } else { cout << "Grade: F 😢" << endl; cout << "Don't give up! Study harder!" << endl; } return 0; }
💬 User Types:
85
▶️ Output:
Enter your test score (0-100): 85
Grade: B 👍
Good job!
⚠️ Important: The computer checks conditions in order from top to bottom. Once one condition is true, it stops checking the rest!
🔗 Using Logical Operators

You can combine multiple conditions using logical operators:

📌 AND (&&) and OR (||) Examples
📄 lesson3.cpp
// AND (&&) — BOTH conditions must be true int age = 16; bool hasPermission = true; if (age >= 16 && hasPermission) { cout << "✅ You can drive!" << endl; } // OR (||) — AT LEAST ONE condition must be true bool isWeekend = true; bool isHoliday = false; if (isWeekend || isHoliday) { cout << "🎉 No school today!" << endl; } // NOT (!) — REVERSES the condition bool isRaining = false; if (!isRaining) { cout << "☀️ Let's go outside!" << endl; }
▶️ Output:
✅ You can drive!
🎉 No school today!
☀️ Let's go outside!
💡 Remember: && = AND (both true), || = OR (at least one true), ! = NOT (reverses)
📋 Quick Reference

🔑 Key Code You Just Learned

if (condition) { } Runs code if condition is true
if (condition) { } else { } Runs one block if true, another if false
if (cond1) { } else if (cond2) { } Checks multiple conditions in order
== Checks if two values are equal
!= Checks if two values are NOT equal
>, <, >=, <= Comparison operators
&& AND — both conditions must be true
|| OR — at least one condition must be true
! NOT — reverses a condition
% Modulo — gives the remainder
