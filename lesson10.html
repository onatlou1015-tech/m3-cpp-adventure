💡 What is Debugging?

Debugging is the process of finding and fixing mistakes (called bugs) in your code.

Even professional programmers spend most of their time debugging — it's a normal and important part of programming!

The word "debugging" comes from an actual moth that was found stuck in a computer in 1947. They literally had to "debug" the computer!

bug debug syntax error logic error runtime error trace
🐛 Types of Bugs

📊 Three Types of Bugs

1. Syntax Errors Mistakes in the rules of C++ (missing semicolons, typos) Program won't compile
2. Logic Errors Code runs but does the wrong thing (wrong formula, wrong condition) Program runs but gives wrong results
3. Runtime Errors Errors that happen while the program is running (divide by zero, out of bounds) Program crashes or freezes
🔍 The good news: The compiler tells you about syntax errors! Logic errors are trickier — you have to figure those out yourself.
🔧 Debugging Steps

📋 Step-by-Step Debugging Process

  1. Read the error message — It tells you the line number and what's wrong
  2. Check the line number — Look at the line the error points to
  3. Use cout to debug — Print variables to see what's happening
  4. Trace your code — Follow the logic step by step
  5. Test with simple inputs — Start with easy values to test
  6. Fix one bug at a time — Don't change too much at once
  7. Test again — Make sure your fix worked
📝 Example 1: Syntax Error
1 Missing Semicolon 🐛

This code has a syntax error — can you find it?

❌ BUGGY CODE
#include <iostream> using namespace std; int main() { int x = 5 int y = 10 cout << "Sum: " << x + y << endl; return 0; }
🐛 BUG: Missing semicolons after x = 5 and y = 10
✅ FIXED CODE
#include <iostream> using namespace std; int main() { int x = 5; // ← Added semicolon int y = 10; // ← Added semicolon cout << "Sum: " << x + y << endl; return 0; }
✅ FIX: Add semicolons at the end of each statement
💡 Pro Tip: When the compiler says "expected ';' before ..." it means you forgot a semicolon on the line above where the error points!
📝 Example 2: Logic Error
2 Wrong Calculation 🐛

This code runs but gives the wrong answer — a logic error!

❌ BUGGY CODE
#include <iostream> using namespace std; int main() { int celsius = 25; // Wrong formula: should be (C × 9/5) + 32 int fahrenheit = celsius * 9 / 5 + 32; // Wait, this is actually right! // The bug is... wait, let me check... cout << "Fahrenheit: " << fahrenheit << endl; return 0; }
🐛 BUG: Using int instead of double — 9/5 = 1 (not 1.8)!
✅ FIXED CODE
#include <iostream> using namespace std; int main() { double celsius = 25; // Use double for decimal precision double fahrenheit = celsius * 9.0 / 5.0 + 32; cout << "Fahrenheit: " << fahrenheit << endl; return 0; }
✅ FIX: Use double instead of int, and 9.0/5.0 instead of 9/5
⚠️ Common Bug: When you divide two ints, C++ does integer division (no decimals). Use double or add .0 to your numbers!
📝 Example 3: Runtime Error
3 Array Out of Bounds 🐛

This code compiles but crashes when you run it!

❌ BUGGY CODE
#include <iostream> using namespace std; int main() { int scores[5] = {10, 20, 30, 40, 50}; // The bug: looping from 0 to 5 (should be 0 to 4) for (int i = 0; i <= 5; i++) { cout << scores[i] << " "; } return 0; }
🐛 BUG: i <= 5 means i goes to 5, but scores[5] doesn't exist!
✅ FIXED CODE
#include <iostream> using namespace std; int main() { int scores[5] = {10, 20, 30, 40, 50}; // Fix: loop from 0 to 4 (i < 5) for (int i = 0; i < 5; i++) { cout << scores[i] << " "; } return 0; }
✅ FIX: Change i <= 5 to i < 5
⚠️ Important: An array of size 5 has indexes 0, 1, 2, 3, 4. Accessing scores[5] is out of bounds and can crash your program!
🔍 Debugging with cout

One of the simplest and most powerful debugging techniques is using cout to print variable values.

Add cout statements to see what's happening inside your program:

📌 Using cout to Debug
🔍 DEBUGGING WITH COUT
#include <iostream> using namespace std; int main() { int total = 0; for (int i = 1; i <= 5; i++) { total += i; // Debug: print what's happening cout << "DEBUG: i = " << i << ", total = " << total << endl; } cout << "Final total: " << total << endl; return 0; }
▶️ Debug Output:
DEBUG: i = 1, total = 1
DEBUG: i = 2, total = 3
DEBUG: i = 3, total = 6
DEBUG: i = 4, total = 10
DEBUG: i = 5, total = 15
Final total: 15
💡 Pro Tip: Remove your cout debug statements once you've fixed the bug — or comment them out with // so you can use them again later!
📋 Common Bugs & Fixes

🔑 Common C++ Bugs and How to Fix Them

Missing ; Add a semicolon at the end of the statement
Misspelled variable Check spelling — C++ is case-sensitive!
Using = instead of == Use == for comparison, = for assignment
Array out of bounds Make sure your loop goes from 0 to size-1
Integer division Use double or add .0 to numbers
Infinite loop Make sure your loop condition changes
Forgetting <string> Add #include <string> when using strings
Forgetting to close { } Count your opening and closing braces
