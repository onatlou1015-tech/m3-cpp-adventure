💡 What is C++?

C++ is a programming language that tells computers what to do. It's used to build video games (like Minecraft!), spacecraft software, movie special effects, and so much more!

In this lesson, you'll learn how to write your very first C++ program and store information using variables — which are like labeled boxes where you can keep numbers, words, and other data.

#include iostream using namespace std int main() cout cin variables int double string bool
📝 Example 1: Your First Program
1 Hello World!

Every programmer starts here! This program prints a friendly message to the screen.

📄 lesson1.cpp
// This is a comment — it's for YOU, not the computer! // Comments help you remember what your code does. #include <iostream> using namespace std; int main() { // cout prints text to the screen cout << "Hello, World!" << endl; cout << "Welcome to C++!" << endl; cout << "Let's have some fun! 🚀" << endl; return 0; }
▶️ Output:
Hello, World!
Welcome to C++!
Let's have some fun! 🚀
💡 Tip: The endl moves to the next line — like pressing "Enter" on your keyboard!
📦 What Are Variables?

Variables are like labeled boxes where you store information. Think of them as:

  • 📦 A box labeled age that stores the number 15
  • 📦 A box labeled name that stores the text "Alex"
  • 📦 A box labeled score that stores the number 95.5

In C++, you need to tell the computer what type of data each variable will hold:

int → whole numbers double → decimal numbers string → text bool → true/false
✏️ How to Create a Variable

Creating a variable in C++ is simple! You just need three things:

  • 1️⃣ Data Type — What kind of data? (int, double, string, etc.)
  • 2️⃣ Variable Name — What do you want to call it? (age, score, etc.)
  • 3️⃣ Value — What data do you want to store? (15, "Alex", etc.)

The basic format is:

dataType variableName = value;

Let's look at some examples:

int age = 15; // Whole number double price = 9.99; // Decimal number string name = "Alex"; // Text bool isPassing = true; // True or false char grade = 'A'; // Single character
✅ Remember: Every variable needs a data type, a name, and a value (unless you want to set it later).
🏷️ How to Name a Variable

Choosing good variable names makes your code easier to read and understand. Here are the rules and best practices:

📏 Naming Rules (MUST FOLLOW)

  • ✅ OK: Can contain letters (a-z, A-Z), numbers (0-9), and underscores (_)
  • ✅ OK: Must start with a letter or underscore (not a number)
  • ✅ OK: Are case-sensitive — age is different from Age
  • ❌ NOT OK: Cannot contain spaces or special characters like @, #, $, %
  • ❌ NOT OK: Cannot start with a number (e.g., 1stPlace is invalid)
  • ❌ NOT OK: Cannot use keywords like int, double, return

💡 Best Practices (GOOD Habits)

  • ✅ Use meaningful names — studentName is better than s
  • ✅ Use camelCase or snake_case — myAge or my_age
  • ✅ Use descriptive names that tell you what the variable stores
  • ✅ Be consistent — pick one style and stick with it!
📝 Variable Naming Examples
📌 Good vs Bad Variable Names

Here are examples of good and bad variable names:

✅ GOOD ❌ BAD Why?
studentName s "s" is too vague — what does it mean?
totalScore totalscore Hard to read without capitalization
birthYear birth year Cannot have spaces in variable names
myAge 1stPlace Cannot start with a number
isPassing int "int" is a keyword — you can't use it
💡 Pro Tip: Good variable names make your code self-documenting — you (and others) can understand what the code does just by reading the names!
📝 Example 2: Using Variables
2 Storing and Printing Data

This program creates variables to store information about a person and then prints it out.

📄 lesson1.cpp
#include <iostream> #include <string> // Needed for text/strings using namespace std; int main() { // Creating variables (like labeled boxes) string studentName = "Alex"; // Text int studentAge = 15; // Whole number double studentHeight = 5.8; // Decimal number char studentGrade = 'A'; // Single character // Printing the variables cout << "Name: " << studentName << endl; cout << "Age: " << studentAge << endl; cout << "Height: " << studentHeight << " feet" << endl; cout << "Grade: " << studentGrade << endl; return 0; }
▶️ Output:
Name: Alex
Age: 15
Height: 5.8 feet
Grade: A
💡 Tip: Notice that string uses "double quotes" while char uses 'single quotes'!
📝 Example 3: Doing Math with Variables
3 Calculating with Variables

Variables can be used in calculations just like in math class!

📄 lesson1.cpp
#include <iostream> using namespace std; int main() { // Variables for a simple calculator int firstNumber = 10; int secondNumber = 5; // Doing math with variables int sum = firstNumber + secondNumber; int difference = firstNumber - secondNumber; int product = firstNumber * secondNumber; int quotient = firstNumber / secondNumber; // Print the results cout << "First Number: " << firstNumber << endl; cout << "Second Number: " << secondNumber << endl; cout << "Sum: " << sum << endl; cout << "Difference: " << difference << endl; cout << "Product: " << product << endl; cout << "Quotient: " << quotient << endl; return 0; }
▶️ Output:
First Number: 10
Second Number: 5
Sum: 15
Difference: 5
Product: 50
Quotient: 2
⚠️ Important: When you divide int numbers, C++ gives you a whole number (no decimals)! Use double for decimals.
