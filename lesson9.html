💡 What is File I/O?

File I/O (Input/Output) is how programs save and load data from files on your computer.

Think of it like this:

  • 📝 Writing to a file = Saving your game progress
  • 📖 Reading from a file = Loading your saved game

This is how games remember your high scores, how apps save your settings, and how programs store data permanently!

ofstream ifstream fstream file read write append
📋 File I/O Classes

🔧 File Stream Classes

#include <fstream> Required for file I/O
ofstream Output file stream — for writing to files
ifstream Input file stream — for reading from files
fstream Can do both reading and writing
file.open("filename.txt") Opens a file (or creates it)
file.close() Closes the file (always do this!)
file.is_open() Checks if the file opened successfully
ios::app Append mode — adds to the end of the file
⚠️ Important: Always close() your files when you're done! This ensures all data is saved properly.

📝 Example 1: Writing to a File
1 Saving a Message to a File

This program writes a message to a text file.

📄 lesson9.cpp
#include <iostream> #include <fstream> // Needed for file operations using namespace std; int main() { // Create an output file stream ofstream myFile; // Open (or create) the file myFile.open("message.txt"); // Check if it opened successfully if (myFile.is_open()) { // Write to the file myFile << "Hello from C++!" << endl; myFile << "This is a saved message." << endl; myFile << "File I/O is awesome! 🚀" << endl; cout << "✅ Message saved to message.txt!" << endl; } else { cout << "❌ Could not open the file!" << endl; } // Always close the file myFile.close(); return 0; }
▶️ Output:
✅ Message saved to message.txt!
📄 message.txt contains:
Hello from C++!
This is a saved message.
File I/O is awesome! 🚀
💡 Notice: Using << with a file works just like cout! You write to the file the same way you print to the screen.
📝 Example 2: Reading from a File
2 Reading a File Line by Line

This program reads a file and displays its contents.

📄 lesson9.cpp
#include <iostream> #include <fstream> #include <string> using namespace std; int main() { // Create an input file stream ifstream myFile; // Open the file myFile.open("message.txt"); // Check if it exists if (myFile.is_open()) { string line; cout << "📖 Reading file contents:" << endl; cout << "------------------------" << endl; // Read and print each line while (getline(myFile, line)) { cout << line << endl; } cout << "------------------------" << endl; cout << "✅ File read complete!" << endl; } else { cout << "❌ File not found!" << endl; } myFile.close(); return 0; }
▶️ Output:
📖 Reading file contents:
------------------------
Hello from C++!
This is a saved message.
File I/O is awesome! 🚀
------------------------
✅ File read complete!
💡 Tip: getline(myFile, line) reads one line at a time. The while loop continues until the end of the file!
📝 Example 3: High Score Tracker
3 Saving and Loading High Scores

This program saves and loads high scores from a file!

📄 lesson9.cpp
#include <iostream> #include <fstream> #include <string> using namespace std; // Function to save a high score void saveScore(string name, int score) { ofstream file; // Open in append mode (adds to the end) file.open("highscores.txt", ios::app); if (file.is_open()) { file << name << " " << score << endl; cout << "✅ Score saved!" << endl; } else { cout << "❌ Error saving score!" << endl; } file.close(); } // Function to display all high scores void showHighScores() { ifstream file; file.open("highscores.txt"); if (file.is_open()) { string name; int score; cout << "\n🏆 HIGH SCORES:" << endl; cout << "---------------" << endl; // Read each name and score from the file while (file >> name >> score) { cout << name << " - " << score << endl; } cout << "---------------" << endl; } else { cout << "📭 No scores saved yet!" << endl; } file.close(); } int main() { int choice; string name; int score; cout << "🎮 HIGH SCORE TRACKER" << endl; do { cout << "\n1. Save a score" << endl; cout << "2. View all scores" << endl; cout << "3. Exit" << endl; cout << "Enter choice: "; cin >> choice; if (choice == 1) { cout << "Enter player name: "; cin >> name; cout << "Enter score: "; cin >> score; saveScore(name, score); } else if (choice == 2) { showHighScores(); } } while (choice != 3); cout << "👋 Goodbye!" << endl; return 0; }

📋 Quick Reference

🔑 Key Code You Just Learned

#include <fstream> Include this for file operations
ofstream file; Creates a file stream for writing
ifstream file; Creates a file stream for reading
file.open("filename.txt"); Opens a file
file.open("file.txt", ios::app); Opens a file in append mode
file << "text" << endl; Writes text to the file
file >> variable; Reads data from the file
getline(file, line); Reads a whole line from the file
file.is_open() Checks if the file opened successfully
file.close(); Closes the file (always do this!)
