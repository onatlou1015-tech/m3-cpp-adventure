🚀 C++ Coding Adventure

Grade 9 · Introduction to Programming
📅 12 Weeks · No Experience Needed

“Coding is the closest thing we have to magic. You type some words, and suddenly—a computer does exactly what you tell it to!”

Welcome to your first programming course! Over the next 12 weeks, you'll learn how to talk to computers using C++ — one of the most powerful and widely-used languages in the world.

🎮 Video Games 🚀 Spacecraft Software 🎬 Movie Effects 📱 Apps

No prior experience needed. Just bring your curiosity, creativity, and a willingness to try!

🎯 Course Objectives

🧠 Think Like a Programmer

  • Break big problems into small steps
  • Use logic and reasoning to solve puzzles
  • Debug (fix) code when things go wrong

✍️ Write Your Own Programs

  • Interactive text-based programs
  • Calculators, games, and quizzes
  • Store and manipulate data

📦 Core Programming Concepts

  • Variables, input/output, decisions
  • Loops, arrays, and functions
  • File I/O and debugging

🏆 Build a Final Project

  • Design your own text adventure game
  • Showcase your work to the class
  • Gain confidence to keep coding
