💡 What are Strings?

A string is a sequence of characters (letters, numbers, symbols) used to represent text.

You've already used strings in earlier lessons! Now we'll learn all the cool things you can do with them.

Think of a string like a train — each character is a carriage on the train. You can count the carriages, find specific ones, add new ones, or change them.

string length concatenation substring find replace upper/lower
📋 Common String Methods

🔧 Useful String Tools

str.length() Returns the length (number of characters)
str[0] Access the character at index 0 (first character)
str.find("text") Finds where "text" appears in the string
str.substr(start, length) Extracts a piece of the string
str1 + str2 Combines (concatenates) two strings
str.append("text") Adds text to the end of the string
str.insert(pos, "text") Inserts text at a specific position
str.erase(pos, length) Removes a portion of the string
str.replace(pos, len, "new") Replaces a portion with new text
💡 Important: Strings, like arrays, start at index 0! So str[0] is the first character.
📝 Example 1: String Basics
1 Creating, Combining, and Getting Length

This program shows how to create strings, combine them, and find their length.

📄 lesson8.cpp
#include <iostream> #include <string> using namespace std; int main() { // Creating strings string firstName = "Alex"; string lastName = "Johnson"; // Combining strings (concatenation) string fullName = firstName + " " + lastName; cout << "Full name: " << fullName << endl; // Getting length cout << "First name length: " << firstName.length() << endl; cout << "Last name length: " << lastName.length() << endl; cout << "Full name length: " << fullName.length() << endl; // Accessing characters cout << "First character: " << fullName[0] << endl; cout << "Last character: " << fullName[fullName.length() - 1] << endl; return 0; }
▶️ Output:
Full name: Alex Johnson
First name length: 4
Last name length: 7
Full name length: 12
First character: A
Last character: n
💡 Tip: str.length() gives you the number of characters. str[0] gives you the first character, and str[str.length() - 1] gives you the last!
📝 Example 2: Searching and Extracting
2 Finding and Extracting Text

This program shows how to search for text and extract parts of a string.

📄 lesson8.cpp
#include <iostream> #include <string> using namespace std; int main() { string sentence = "I love programming in C++!"; // Finding text int pos = sentence.find("programming"); cout << "'programming' found at position: " << pos << endl; // Finding text that doesn't exist int notFound = sentence.find("Python"); if (notFound == string::npos) { cout << "'Python' not found! ❌" << endl; } // Extracting a substring string sub = sentence.substr(7, 11); // Start at 7, take 11 characters cout << "Substring: '" << sub << "'" << endl; return 0; }
▶️ Output:
'programming' found at position: 7
'Python' not found! ❌
Substring: 'programming'
⚠️ Important: find() returns string::npos if the text isn't found. Always check for this!
📝 Example 3: Modifying Strings
3 Changing Case and Modifying Text

This program shows how to change case, replace text, and modify strings.

📄 lesson8.cpp
#include <iostream> #include <string> #include <cctype> // For toupper() and tolower() using namespace std; int main() { string text = "Hello World!"; // Convert to uppercase (character by character) string upperText = ""; for (char c : text) { upperText += toupper(c); } cout << "Uppercase: " << upperText << endl; // Convert to lowercase (character by character) string lowerText = ""; for (char c : text) { lowerText += tolower(c); } cout << "Lowercase: " << lowerText << endl; // Replacing text string message = "I like cats!"; cout << "Original: " << message << endl; int catPos = message.find("cats"); message.replace(catPos, 4, "dogs"); cout << "Replaced: " << message << endl; // Inserting text message.insert(0, "Actually, "); cout << "Inserted: " << message << endl; return 0; }
▶️ Output:
Uppercase: HELLO WORLD!
Lowercase: hello world!
Original: I like cats!
Replaced: I like dogs!
Inserted: Actually, I like dogs!
💡 Pro Tip: C++17 and later have std::transform for easier case conversion, but this manual method works everywhere!
🔐 Real-World Example: Password Checker
📌 Password Strength Checker

This program checks if a password is strong enough!

📄 lesson8.cpp
#include <iostream> #include <string> using namespace std; int main() { string password; cout << "🔐 Password Strength Checker" << endl; cout << "Enter your password: "; cin >> password; // Check length int len = password.length(); bool hasUpper = false; bool hasLower = false; bool hasDigit = false; bool hasSpecial = false; // Check each character for (char c : password) { if (isupper(c)) hasUpper = true; if (islower(c)) hasLower = true; if (isdigit(c)) hasDigit = true; if (!isalnum(c)) hasSpecial = true; } // Rate the password cout << "\n📊 Password Analysis:" << endl; cout << "Length: " << len << " characters" << endl; int score = 0; if (len >= 8) score++; if (hasUpper) score++; if (hasLower) score++; if (hasDigit) score++; if (hasSpecial) score++; cout << "Strength: "; if (score <= 2) { cout << "❌ Weak" << endl; cout << "Add more characters, numbers, and symbols!" << endl; } else if (score <= 3) { cout << "⚠️ Medium" << endl; cout << "Add a symbol for extra security!" << endl; } else { cout << "✅ Strong" << endl; cout << "Great password! 🔒" << endl; } return 0; }
💬 User Types:
MySecurePass123!
▶️ Output:
🔐 Password Strength Checker
Enter your password: MySecurePass123!

📊 Password Analysis:
Length: 16 characters
Strength: ✅ Strong
Great password! 🔒
💡 Fun Fact: Real password checkers use the same techniques! They check length, uppercase, lowercase, numbers, and special characters.
